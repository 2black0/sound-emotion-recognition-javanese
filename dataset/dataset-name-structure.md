Each audio file is named in the format:

```
aa-bb-cc-dd.wav
```

* `aa`: Actor ID (01–10)
* `bb`: Sentence ID (01–04)
* `cc`: Emotion Code (01–06)
* `dd`: Repetition Number (01–07)

#### Emotion Codes:

* `01` - Neutral
* `02` - Sadness
* `03` - Happiness
* `04` - Surprise
* `05` - Fear
* `06` - Anger

#### Example:

```
01-02-03-04.wav
```

* Actor 01
* Sentence 02
* Emotion: Happiness
* 4th Repetition
